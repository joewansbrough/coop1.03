# Automated Guided Spotlight Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a guided interactive auto-demo that moves a synthetic cursor, spotlights real product areas, and explains coopHUB BC selling points while waiting for viewer confirmation.

**Architecture:** Add a typed auto-demo definition module, a React overlay mounted in demo mode, stable `data-demo-target` anchors on important UI surfaces, and a launch path from the existing demo track picker. Keep the existing manual demo guide intact.

**Tech Stack:** React 19, TypeScript, Vite, React Router hash routes, localStorage demo mode, lucide-react icons, existing `npx tsx` test pattern.
